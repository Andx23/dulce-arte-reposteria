# Dulce Arte | Repostería Artesanal

Sitio web para un emprendimiento de repostería artesanal, diseñado para presentar productos, explorar un catálogo y facilitar la solicitud de pedidos mediante WhatsApp.

## Descripción

**Dulce Arte** es un proyecto de desarrollo web frontend creado para un negocio de repostería artesanal ubicado en Modelia, Bogotá, Colombia.

El sitio busca ofrecer una experiencia visual agradable, facilitar la consulta de productos y permitir que los clientes personalicen sus pedidos antes de enviar una solicitud por WhatsApp.

## Características

- Presentación del emprendimiento y su identidad visual.
- Sección de productos destacados.
- Catálogo organizado por categorías.
- Visualización y personalización de productos.
- Carrito de compras.
- Cálculo de precios y aplicación de promociones.
- Formulario para recopilar los datos del cliente.
- Selección entre recogida en el local y domicilio.
- Resumen del pedido.
- Integración con WhatsApp para enviar solicitudes.
- Secciones de testimonios, ubicación e información del negocio.
- Diseño adaptable a dispositivos móviles y escritorio.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido semántico.
- **CSS3:** estilos, diseño visual y adaptación responsive.
- **JavaScript Vanilla:** lógica e interactividad del sitio.

No se utilizan frameworks de JavaScript ni backend.

## Instalación y ejecución

1. Clona el repositorio:

```bash
git clone https://github.com/USUARIO/dulce-arte-reposteria.git
```

2. Ingresa a la carpeta:

```bash
cd dulce-arte-reposteria
```

3. Abre el archivo `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code.

## Flujo de pedidos

1. El cliente explora el catálogo.
2. Selecciona los productos y sus opciones.
3. Agrega los productos al carrito.
4. Completa sus datos y selecciona el método de entrega.
5. Revisa el resumen.
6. Envía la solicitud mediante WhatsApp.

**Importante:** el envío por WhatsApp corresponde a una solicitud de pedido. La disponibilidad, los precios pendientes de cotización y el costo del domicilio deben ser confirmados por el negocio.
